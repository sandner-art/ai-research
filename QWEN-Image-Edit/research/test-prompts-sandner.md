## Technical Notes for Qwen-Image Optimization

### Prompt Structure Elements Used:
1. **Subject Description**: Detailed, natural language (not weight syntax)
2. **Technical Specifications**: Camera, lens, aperture naturally integrated
3. **Lighting Details**: Specific time of day, quality, direction
4. **Color Information**: Palette description, mood, grading
5. **Composition**: Rule of thirds, perspective, framing
6. **Texture Details**: Surface qualities, material properties
7. **Resolution**: Appropriate K value for subject type
8. **Style Keywords**: Photography genre, processing style
9. **Emotional Content**: Mood, atmosphere, feeling

### Why These Work for Qwen-Image:
- Natural language vs. SD weight syntax
- Leverages 32K token context for comprehensive descriptions
- Text rendering capabilities for any signage in scenes
- Multilingual understanding for location-specific content
- Semantic comprehension of photography techniques
- No artificial LoRA references needed

### Adaptation Guidelines:
- Remove SD syntax like `(term:1.2)` → "emphasized term"
- Remove LoRA calls → describe desired effect
- Expand abbreviations (HDR → High Dynamic Range processing)
- Add contextual details (time, location, technical specs)
- Use complete sentences and natural flow
