## Technical Notes for Qwen-Image Optimization

### Prompt Structure Elements Used:
1. **Design Description**: Detailed natural language for elements, theory, and harmony
2. **Typography Specifications**: Font styles, kerning, integration naturally described
3. **Color Details**: Specific harmonies, palettes, and symbolic uses
4. **Composition**: Theory applications like balance, alignment, hierarchy
5. **Texture and Effects**: Materials, renders, and creative enhancements
6. **Resolution**: Scaled K values for detail and scalability
7. **Style Keywords**: Genre, media, and output simulation
8. **Creative Tests**: Elements to challenge adherence and innovation

### Why These Work for Qwen-Image:
- Leverages text rendering for crisp typography and labels
- Utilizes long context for complex design descriptions
- Tests semantic understanding of design theory and harmony
- Encourages creative outputs while adhering to prompts
- No syntax weights; pure natural language for model strengths
